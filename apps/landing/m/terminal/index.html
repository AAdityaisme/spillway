01 · POLICY

A budget is a config block.

Limits cascade org → team → key. The gateway evaluates them on every request — declared once, enforced everywhere.

gateway/policy.budgets.ts
export const budgets = {
  org: {
    acme: { limit: 20_000, period: "month" },
  },
  team: {
    platform: { limit: 5_000, on_exceed: "block" },
  },
  key: {
    batch_embed: {
      limit: 1_000, period: "day",
      on_exceed: "block",  // 402 before the provider is called
    },
  },
} satisfies BudgetPolicy;
