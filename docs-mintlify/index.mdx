Spillway is an OpenAI- and Anthropic-compatible AI gateway with a governance brain:
hierarchical budgets with **hard enforcement**, guardrail policies, approval workflows, and
cost-aware routing, sitting in front of every model call your organization makes.

You point your existing SDK at Spillway instead of the provider directly. Every request is
then metered, priced, governed, and logged before — not after — it reaches the provider.

## The two planes

| Plane   | Base URL | Auth                                                        | What it is                                              |
| ------- | -------- | ------------------------------------------------------------ | -------------------------------------------------------- |
| Data    | `/v1/*`  | `Authorization: Bearer mk-live-…` (or `x-api-key`)            | The LLM gateway. Your SDK points here.                    |
| Control | `/api/*` | Session token, or `mka-…` admin key + `X-Spillway-Org` header | Dashboard and machine API: keys, budgets, approvals, reports. |

Local dev serves both planes from `http://localhost:3000`.

## What governance actually means here

Most gateways log spend after the fact. Spillway's guarantees are enforced **before** the
request leaves the building:

- **Budgets that block.** A budget in `enforce` mode returns `402` before the provider is
  called once a scope's spend for the period would exceed its limit — no upstream call, no
  charge, no surprise invoice.
- **Guardrail policies.** Match on virtual key, team, model, or metadata; deny, flag, or
  require approval. Evaluated on every request, not sampled.
- **Approval workflows.** A policy can gate a request behind a multi-step, tiered approval
  chain instead of an outright deny.
- **Cost-aware routing.** Routing rules rewrite a model to a cheaper equivalent or a
  fallback chain, evaluated per request before dispatch.
- **A ledger, not a log.** Every request — including every block — is written as a row with
  its cost, scope, and outcome, so budgets, alerts, and chargeback reports are always
  reconciled against what actually happened.
